# PR Creation Guidelines

When creating a pull request (PR) in this repository, please follow these guidelines to ensure a smooth review process:

1. **PR Title**: The PR title should be concise and descriptive, summarizing the changes made. It should ideally be in the format: `[Type] Short Description`. For example: `[Feature] Add new API endpoint for user authentication`.

2. **PR Description**: The PR should match the template provided in the repository, if available. You should not remove any sections or add new sections to the template.
