# Branch Creation Guidelines

When creating a new branch for your work, please follow these guidelines to maintain consistency and clarity in our version control:

1. **Branch Creation**: If the branch is related to an issue, create a branch from the issue(by a tool if available, else through the command line)
2. **Branch Naming**: The branch name should be prefixed with the type of change (e.g., `feature/`, `bugfix/`, `refactor/`, `docs/`), followed by the issue number(if relevant), followed by a concise description of the change. For example: `feature/add-new-api-endpoint`.
